# Михаил Пахомычев — личный сайт

Черновик страницы о практике: отдел продаж для B2B под ключ, Smart Sales и AI-трансформация продаж. Статическая вёрстка, форма заявку никуда не отправляет.

Публичная копия: https://anthemium.github.io/pakhomychev/

## Как открыть локально

Из этой папки (`site`):

```powershell
python -m http.server 4173
```

Дальше в браузере: http://127.0.0.1:4173/

Через `npx serve` тоже можно:

```powershell
npx --yes serve -l 4173
```

Файл `index.html` лучше смотреть через локальный сервер, а не двойным щелчком: так одинаково открываются стили, шрифт и фото.

## Что изменилось

Страница собрана заново как обычный HTML. Цвета, шрифт Manrope, «пилюли» навигации, крупный заголовок и чередование белых и серых секций взяты у прежней локальной вёрстки. Абсолютные блоки Tilda не вмещали новые тексты, фото и три направления, поэтому координаты блоков не правились точечно.

После трёх направлений на главной стоит короткий список категорий управления продажами B2B: только названия, без расшифровки.

- Имя, телефон, реквизиты и кейсы прежнего консультанта с публичной страницы убраны.
- В меню три направления: B2B под ключ, Smart Sales, AI-трансформация.
- Кейсы — рабочие периоды из резюме. Цифры, которых не было в резюме или на приложенных кадрах, не добавлялись.
- Портрет, грамота Skillbox, пост «Итоги июля», реплика Егора Волкова, переписка и фото с главой Минцифры лежат в `assets/photos/`.
- Юридические страницы — короткая заглушка: политика появится, когда будет известно юридическое лицо.
- Форма в `js/local-forms.js` только показывает сообщение в браузере.

## Что из резюме не публиковалось

На сайт, в этот файл и в репозиторий не переносились поля поиска работы: адрес и станция метро, гражданство и разрешение на работу, готовность к переезду и командировкам, желаемая должность и зарплата, специализации в формулировке «ищу работу», тип занятости, формат работы и время в пути.

Взяты опыт, компании, результаты, навыки, образование, рабочий текст «о себе» и рабочие контакты: телефон, почта, Telegram. Исходный PDF в репозиторий не входит.

## Что где править

| Файл | Что это |
| --- | --- |
| `index.html` | Главная: тексты, кейсы, подписи к фото |
| `assets/local.css` | Цвета, шрифт, отступы, сетка |
| `assets/photos/` | Портрет и документы |
| `js/local-forms.js` | Поведение формы без отправки |
| `legal/` | Заглушки про данные, согласие и рассылку |

Папки `_archive/` и `assets/cdn/` — локальный след прежней выгрузки. В git они не входят.

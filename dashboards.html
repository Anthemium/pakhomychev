Примеры дашбордов

Публичные репозитории, содержимое которых проверено по README или по файлам примера.

Это не отчёты клиентов. Учебные суммы из датасетов сюда не переносятся. Скриншоты из репозиториев без ясной лицензии на переиспользование на страницу не ставились.

Apache Superset · Apache-2.0 · пример в дереве проекта

Sales Dashboard

Решение: где сосредоточена выручка по линейке и размеру сделки в учебном каталоге. В манифесте дашборда — выручка, число проданных позиций, квартальная выручка, доля выручки по линейке, выручка по размеру сделки, сезонность, статус заказа. Фильтры: страна, штат, индекс, количество, диапазон дат, MSRP. Авторский текст примера прямо указывает: это продажи техники на выборке заказов 2003–2005 годов, не живая CRM.

  • Запаздывающие: выручка, количество, структура по продукту.
  • Опережающие пайплайна — покрытие, конверсия этапов, точность прогноза — в этом примере не собраны.

Стек: Apache Superset. github.com/apache/superset · examples/sales_dashboard

Flask · карточка возможности

Sales Pipeline Dashboard

Решение: какие открытые возможности входят в прогноз и как распределена нагрузка по продавцам. В схеме репозитория у возможности есть сумма, вероятность, этап и ожидаемая дата закрытия. Отчёты README: разрез по этапам, результат по представителю, расчёт прогноза выручки.

  • Запаздывающие в этом приложении не выделены отдельным блоком факта.
  • Опережающие: этап, вероятность, ожидаемая дата, прогноз выручки.

Стек: Python, Flask, SQLite, SQLAlchemy. Публичного деплоя в README нет. github.com/Nabbonnita-ECS/SalesPipelineDashboard

Power BI · файл .pbix в репозитории

Sales Pipeline Dashboard, учебный разбор 2017

Решение, которое README называет целью файла: здоровье воронки, квартальный и месячный ход возможностей и выручки, аллокация по региону, продукту и сектору. Заявленный набор: выручка, число возможностей, доля успеха, длина цикла в днях. Автор сам отмечает ограничение данных: в выборке возможности помечены как выигранные. Суммы из README на эту страницу не переносятся.

  • Запаздывающие: выручка, доля успеха, длина цикла.
  • Опережающие: возможности по этапам и периодам. Точность прогноза в README не описана.

Стек: Power BI. github.com/yogesh8536/Sales-Pipeline-Dashboard

Streamlit · розничная выгрузка Excel

Sales Dashboard, Sven Bosau

Решение: операционный контроль транзакционной точки, не квота B2B. В коде приложения три показателя шапки — сумма продаж, средняя оценка, средний чек транзакции — и два разреза: линейка продуктов и час. Источник данных в коде: файл supermarkt_sales.xlsx.

  • Запаздывающие: сумма, средний чек, оценка.
  • Покрытие пайплайна, конверсия этапов, win rate и точность прогноза в коде не считаются. Пример полезен как граница: дашборд продаж и дашборд отдела B2B — разные объекты.

Стек: Python, Streamlit, Plotly, pandas. Репозиторий · демо

Streamlit · прогноз спроса

AI Sales Forecasting Dashboard

Решение: как двигаются продажи, прибыль, заказы и скидка в электронной коммерции и каким будет ряд дальше. README фиксирует фильтры по дате, региону и категории и прогноз Prophet. Это прогноз временного ряда, не категории прогноза сделки.

  • Запаздывающие: продажи, прибыль, заказы, скидки.
  • Опережающий объект — прогноз ряда. Win rate, цикл сделки и покрытие квоты в описании нет.

Стек: Streamlit, Plotly, Prophet, pandas. Репозиторий · демо

Streamlit · MIT

MarketIQ

Решение: операционная картина выручки и заказов плюс горизонт на шесть месяцев. README описывает KPI выручки, заказов и клиентской активности и прогноз Prophet по истории продаж. Покрытие квоты и конверсия этапов в описании не заданы.

  • Запаздывающие: выручка, заказы, активность клиентов.
  • Опережающий объект — шестимесячный прогноз ряда.

Стек: Streamlit, SQLAlchemy, SQLite или PostgreSQL, Plotly, Prophet. Лицензия MIT. github.com/AmirhosseinHonardoust/Market-IQ
